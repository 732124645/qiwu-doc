# 智能助手

**智能助手**从业务页面右侧的悬浮按钮打开。业务人员用自然语言提要求，模型 / 智能体就**用后台自己的工具、以这个用户本人的身份**去办：查数据、做汇总、按要求修改数据；需要外部信息时，它联网搜索并阅读网页。默认的“询问”模式会先把“改哪条记录、每个字段的旧值 → 新值、依据哪些来源”列出来，**由人确认后才执行**。本人可按下文的[审批模式](#工具策略和审批模式)、[自动审查](#自动审查)和[自动化](#自动化)规则授权部分写入，无须每次重复确认。

还可以在列表里勾选多条记录，让智能体对每一条批量执行同一个技能（比如“补齐客户信息”），结果进批次审批页，逐条或一次确认。也可以把一个技能或一段提示词做成**自动化**，让它按时、在某个业务操作之后或手动在后台运行，结果进收件箱。

智能体只通过工具办事：工具就是各模块已有的 MCP 工具（和 [MCP 智能体接入](/features/mcp)用同一份工具清单和同一套检查），再加上内置的联网、计划清单和反问。它不执行命令、不读写服务器上的文件、不操作浏览器。

::: tip 默认关闭
智能助手默认关闭，不需要的项目可以跳过这一页。它运行在现有的 Redis 任务队列和 Socket.IO 推送上，不需要新的服务。完整说明见仓库的[后台智能体文档](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md)。
:::

## 打开开关

| 开关 | 在哪里 | 作用 |
| --- | --- | --- |
| `APP_AGENT` | 服务端环境变量，默认 `false` | 只在启动时读取，改完要重启**全部**服务端实例。关闭时整个模块不加载：`/api/agent/*` 全部返回 404，侧栏、角色授权树和租户套餐里都看不到 **智能体** 菜单组，页面右侧的悬浮入口也不出现 |
| `agent.paused` | **系统管理 → 参数设置**，默认 `false`，**只有超级管理员（root）能改** | 急停：改成 `true` 后拒绝新的对话和工具调用，正在运行的对话在半秒内停下；改回 `false` 就恢复。不需要重启，所有实例同时生效 |

`APP_AGENT` 和 `APP_MCP` 互不依赖：只开智能助手时，`/api/mcp` 仍然不存在。数据表始终由迁移创建，菜单和示例数据始终由种子写入，打开开关时不需要另外迁移。部署时的注意事项（出口防火墙、密钥）见[部署 · 智能助手](/guide/deploy#智能助手)。

打开后的第一步：

1. 超级管理员在 **智能体 → 智能体设置** 的“模型”页签里添加一个模型提供方（见下节）。没有可用的模型时，对话页提示联系管理员，输入框不能用；
2. 需要联网时，在“联网搜索”页签添加一个搜索服务商；
3. 在 **系统管理 → 角色管理** 里给业务角色勾选 **智能助手**；技能管理、批量执行、用量和自动化页要分别授权；
4. 开启[多租户](/features/multi-tenancy)时，先把 **智能体** 菜单组勾进租户套餐，这个租户的角色才能被授权。

自 v1.11.0 起，聊天从右侧悬浮入口打开，不再占侧栏菜单；设置、技能、用量和自动化仍在 **智能体** 菜单组中。原会话路由保留，用于授权、通知、分享和已有链接：

| 页面 | 内容 |
| --- | --- |
| **右侧智能助手入口** | 当前页面旁的聊天面板；会话与批次审批路由保留，但不显示为侧栏菜单 |
| **智能体 → 技能管理** | 个人和全租户的技能、提示词模板、租户说明 |
| **智能体 → 智能体设置** | 模型、联网搜索、外部 MCP、工具策略、平台技能、说明与限额，以及只给超级管理员的“诊断”页签。多租户时是平台专属页面，改动只有超级管理员能做 |
| **智能体 → 智能体用量** | 按日、用户或模型汇总积分与实际用量，分页查看每次调用的费率快照 |
| **智能体 → 自动化** | 按定时、业务事件或手动在后台运行的技能和提示词，以及运行历史，见下文[自动化](#自动化) |

见仓库的[启用](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#启用)。

## 配置模型

模型经**兼容 OpenAI 的接口**（Chat Completions）接入。在 **智能体 → 智能体设置** 的“模型”页签填写提供方名称、接口地址、密钥和模型列表，可设为默认。模型需要支持**工具调用**（function calling）；本地服务不需要密钥时留空。

自 v1.11.0 起，每个模型还要明确配置积分费率，单位是**每百万 Token 消耗多少积分**，不绑定货币或汇率：

| 费率 | 计量方式 |
| --- | --- |
| 普通输入 | 输入总量中不属于单独缓存计价的部分 |
| 输出 | 提供方实际报告的输出总量，包含其中的推理 Token |
| 缓存读取 | 替换相应输入部分的费率，不再加到输入总量上收费 |
| 缓存写入 | 替换相应输入部分的费率，不再加到输入总量上收费 |

- 缓存费率留空表示沿用普通输入；明确填写 `0` 才表示该类免费。费率最多保留 6 位小数，积分用整数精确计算，每次调用合计后只舍入一次。
- 旧模型没有费率时会标为“待配置”，**发请求前就拒绝调用**，不会默认当成免费。升级后先补费率，再设置预算。
- 推理是输出的细分，不重复扣分；缓存也是输入的细分。用量页同时保留总量和细分，不能把它们全部相加。
- 模型能力和默认思考行为分开设置：提供方默认、明确关闭，或模型支持的强度。标准协议使用模型支持的推理参数；vLLM 协议只显示开／关，不伪装为低、中、高三个等级。取消“支持思考”的声明不等于向上游发送关闭指令。
- 密钥**只写不读**，加密存库；改了接口地址必须重新填，原密钥不会发送到新地址。
- 会话可选择已配置的提供方与模型。模型服务报错只显示简短原因，不回显对方正文或密钥。

各家接口地址、上下文窗口、图片能力和设置说明见仓库的[配置模型](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#配置模型)。

## 联网搜索

智能体有两个内置的只读联网工具：一个搜索公网，一个阅读网页。

- 搜索服务目前支持**博查**（国内）和 **Tavily**（海外），在“联网搜索”页签添加，密钥同样加密存库、只写不读。没有配置搜索服务时，不提供搜索；
- 读网页**只能读**这一轮搜索结果里出现过的链接、用户在消息里给出的链接，或者管理员列进白名单的网站，防止网页内容诱导智能体把内部数据拼进网址发出去；
- 系统参数 `agent.web.mode` 设为 `off` 时，完全不提供联网工具。

见仓库的[联网搜索](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#联网搜索)。

## 外部 MCP 服务器

在“外部 MCP”页签里可以接入本系统以外的 MCP 服务器（Streamable HTTP 传输），让智能体也能用它们的工具。

- 鉴权可以不填、填一个请求头令牌，或者用 OAuth 客户端凭据，凭据加密存库、只写不读；
- 默认只能连接公网地址，要指向内网必须由超级管理员明确勾选允许；
- 点“同步”列出服务器上的工具。新工具默认**停用**，管理员逐个启用并设置审批策略；外部服务器自称“只读”不可信，只有超级管理员明确设为直接执行的工具才不用确认；提示未知时也必须明确核对服务器和工具后再信任，这不是系统已验证其只读性的证明；
- 服务器在调用中途需要用户补充信息时，对话页显示一张表单卡片。

见仓库的[外部 MCP 服务器](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#外部-mcp-服务器)。

## 工具策略和审批模式

自 v1.9.1 起，已收录工具的名称、用途说明和已知权限按页面语言显示，中文界面可以直接阅读；工具标识仍保留供核对，未知工具或权限保留原文，不改变工具协议中的名称和参数。

“工具策略”页签列出本系统的全部工具，每个设一个审批策略，对所有租户生效：

| 策略 | 含义 |
| --- | --- |
| 自动执行（`auto`） | 直接执行，只读工具的默认值 |
| 询问（`ask`） | 停下来等发起人确认，写入工具的默认值 |
| 自动审查（`review`） | 只给写入工具：会话选了“自动审查”模式时先交审查模型判断，其余情况照“询问”，见下文[自动审查](#自动审查) |
| 禁用（`deny`） | 智能体看不到这个工具 |

本系统的写入工具只能是“询问”“自动审查”或“禁用”，不能设成自动执行；外部工具的直接执行取决于上述超级管理员明确给出的信任。声明必须逐次本人确认的工具仍保持逐次确认。在 MCP 工具页整体停用的工具，智能体同样用不了。

每个会话还可以切换**审批模式**：

- **只读**：只提供只读工具；
- **询问**（默认）：每次写入都要确认；
- **信任本会话**：同一个工具对同一条记录确认过一次后，本会话内不再询问。超级管理员可以用参数 `agent.trust_mode` 关掉这个选项；
- **自动审查**：平台指定了审查模型时才有这个选项，设为“自动审查”的写入先交审查模型判断。

审批卡片列出工具、要改的记录、每个字段的旧值 → 新值和这一轮读过的来源，按钮是“确认执行”“本会话内同意”“拒绝”“取消本轮”。拒绝时可以写一句理由，智能体不会再重试。除了“信任本会话”中已确认的同工具、同记录写入，管理员和本人都同意的自动审查，以及自动化里本人输入密码给出的[预先同意](#自动化)，**写入都要有人逐次确认**。

另外还有**计划模式**：智能体只读，先列出要做的步骤，你确认后再切回执行。

见仓库的[工具策略](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#工具策略)和[聊天面板](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#聊天面板)。

v1.10.0 中，每张助手准备的申请都要求本人在单张卡片逐次确认，不能用会话信任、自动审查、自动化预先同意、批量同意或直接 MCP / PAT 代替。当前公开版通过 [OA 办公](/features/oa)和审批中心直接办理。

## 自动审查

自动审查让一类影响小的写入不必每次都等人点确认，而是先由另一个模型（审查模型）看一遍。要同时满足三件事：

1. 超级管理员在系统参数 `agent.review.model` 里指定审查用的模型；没指定时，会话里没有“自动审查”这个模式；
2. 管理员在“工具策略”（或外部 MCP 的工具列表）里把某个写入工具设为 **自动审查**；
3. 发起人在会话里把审批模式切到 **自动审查**。

之后这个工具的写入先交审查模型判断，结果有三种：**放行**（直接执行，卡片记为“已自动审查通过”并附理由）、**驳回**（不执行，智能体被告知不要重试）、**交给人**（照常等你确认，卡片附上审查的说明）。审查模型出错或超时、回答格式不对、内容太长需要截断、本轮已送审 10 次、积分预算用完等情况，一律交给人，从不默认放行。审查模型只看到你在本会话里说过的话、工具、参数、改动预览和来源链接，看不到任何工具的输出或网页正文。

::: warning 局限
审查模型同样可能判断错误，或被精心构造的参数、业务数据和上下文误导；它只能对照你在会话里说过的话，并不理解业务规则，也不替代权限和数据范围（工具仍按发起人本人的权限执行）。建议只对影响小、可以撤销的写入开启（比如改备注、加标签），删除、批量修改、对外发送和涉及金额的写入保持“询问”。每次放行都在审批卡片和操作日志里留有记录，可以事后核对。
:::

见仓库的[自动审查](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#自动审查)。

## 反问和选项

智能体拿不准时（比如搜到几家名字相近的公司），会停下来问你：一次 1 到 4 个问题，每题 2 到 4 个选项（单选或多选），另有“其他”可以自己填。这一轮会停下等你回答，你也可以选择不回答。你填的文字只当作数据交给模型。

## 对话页

自 v1.11.0 起，点击业务页面右侧的 **智能助手** 打开聊天面板。桌面可收起或展开，手机为全宽；当前业务地址、筛选和页面状态保留。旧的独立会话地址继续服务通知、分享和已有链接。

- **会话和草稿**：历史列表按需打开，支持新建、搜索、改名、置顶、归档和删除。收起后重开保留会话与草稿；新页面上下文只用于新会话，不悄悄替换已有草稿来源。身份、租户或权限变化会清理面板状态。
- **收起与停止**：输入区单独按 Esc 收起面板，后台任务继续；停止任务使用 **停止** 按钮或带修饰键的自定义快捷键。候选菜单和审批卡已消费的按键不会同时关闭宿主。独立页原有停止快捷键保留。
- **回答阅读**：流式显示回答，工具调用和思考摘要可折叠；支持表格、嵌套列表、任务清单、代码复制与折行、Markdown 原文切换、下载原文和展开阅读。HTML 按文字显示，外部 Markdown 图片不会自动加载。
- **工作面板**：按需汇总当前会话的任务、来源和报告、图表、图片等产物。宽容器并排显示，窄容器使用抽屉；切换会话立即清除旧预览，审批仍只在原确认卡片办理。
- **子任务**：按真实状态分组，显示进行中与已结束数量、各项状态和摘要。点击后在主任务旁只读查看过程；手机提供返回主任务入口，不切走主会话。分享快照不能额外读取私有子会话。
- **分叉、重发和撤回**：从任意消息分叉，或编辑最后一条消息后重发；撤回删除最后一轮，**已经执行的修改不会回滚**。进行中的会话须先停止，结果未知的操作须先本人核对，才能分叉、撤回或删除，不能用这些动作清掉未解决的风险。
- **分享与导出**：同租户只读链接和 Markdown 导出；分享者不能因此扩大查看者的业务权限。
- **运行中发消息**：可追加到本轮改方向，或排到下一轮；附件仍按当前文件权限读取。
- **斜杠命令和提醒**：输入 `/` 使用新会话、压缩、模型、审批模式、技能和状态等命令；等待确认、反问和较长任务完成时仍发站内信，可另开邮件。

见仓库的[聊天面板](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#聊天面板)。

### 断线、刷新与发版

- **发送结果不明**：同一次发送使用同一个 UUID，服务器保留接收凭据。回执丢失后只查询接收结果，不自动重新发送；明确重试沿用原标识。浏览器会话存储只保留按本人和租户隔离的标识，不保存消息正文；整页刷新不保证保留未发送的明文草稿，须先核对上次发送再输入新消息。
- **回答补齐**：流式文字约每 200 毫秒批量保存，先存数据库再广播，携带版本和 UTF-16 位置；重连可补齐已经显示的前缀。服务器重启后恢复的是任务，**不是原模型连接上的 Token 续传**；当前步骤可能中断并需要重新生成，队列和租约会影响等待时间，没有固定恢复秒数。
- **结果未知时暂停**：写入或付费图片调用没有可信结果时，暂停后续写入和图片生成；仍可只读查询，查询涉及的模型调用照常计量；会话信任、自动审查和自动化都不能绕过。本人先核对业务是否完成、费用是否发生，再按当前风险版本确认解除；这只允许后续操作，旧轮次和排队消息不会自动重放。自动化遇到结果未知会停用并撤销预授权，需另行重新配置。
- **先核对再继续**：本地写入超时或缺少可信输出也算结果未知，原工作尚未实际结束时不能解除暂停。远程非幂等操作要到对方系统核对，不能保证任意外部系统都只执行一次。

## 技能

**技能**是一段任务说明，加上这项任务允许用的工具。比如“补齐客户信息”：逐个联网查官网、行业、城市……只填空字段，并写明来源。技能只是说明文字，不含可以执行的代码。

| 范围 | 谁维护 | 谁能用 |
| --- | --- | --- |
| 平台 | 超级管理员，在 **智能体设置** 的“平台技能”页签 | 所有租户的所有用户 |
| 租户 | 有技能管理权限的人，在 **智能体 → 技能管理** | 本租户的用户 |
| 个人 | 自己，在 **智能体 → 技能管理** | 自己 |

同名时个人的优先，其次是租户的，最后是平台的。

- 平时模型只看到技能的名称和描述，判断要用时才读取正文；
- 在输入框里打 `$` 加技能名（或用 `/skills`）可以直接指定技能；技能列了工具时，这一轮只提供这些工具；
- 一次对话做得好，可以点“存成技能”，让模型根据这次对话起草一个个人技能，保存为未启用，检查后再启用；
- 技能可以按 `SKILL.md` 格式导入、导出。

格式和写法见仓库的[技能](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#技能)。

## 说明、语气和提示词模板

- **说明**拼在给模型的系统提示里，依次是：平台说明（超级管理员）→ 租户说明（**技能管理** 页）→ 个人说明（每个人自己写，比如“回答用表格”）；
- **语气**是个人选项：默认、简洁、详细、亲切、正式；
- **提示词模板**是常用的提问，分个人和全租户两种，在输入框里用 `/prompts` 插入。

见仓库的[说明、语气与提示词模板](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#说明语气与提示词模板)。

## 配置方案

**配置方案**是一套命名的设置：模型和推理强度、审批模式、允许使用的工具清单，以及一段额外说明。对话页头部的 **配置方案** 按钮打开列表，可以新增、编辑、删除。

- 方案分**个人的**和**全租户共用的**（后者的增改删需要技能修改权限），别人的个人方案看不到；每个范围可以设一个默认；
- 新建会话时在头部选一个方案（默认选中自己的默认方案，没有时用全租户默认），也可以选“不用方案”；
- **全租户方案的审批模式只能是“只读”或“询问”**：“信任本会话”和“自动审查”等于替本人同意写入，只能由本人在个人方案或会话里选；
- 自 v1.9.1 起，允许的工具可以从本人可用的系统工具中多选，也可以输入其他工具标识（如内置或外部 MCP 工具）；不选表示不限制。工具列表载入失败时会提示，原有选择仍保留；
- 给了工具清单时，智能体只能用清单里的工具（只读的内置工具总可以用）；额外说明作为背景放进每次请求。选择或补录工具不会授予额外权限，也不会绕过审批策略。

见仓库的[配置方案](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#配置方案)。

## 记忆

每个人有一个只属于自己的记忆库。对话页头部的 **我的记忆** 按钮打开列表，可以搜索、新增、编辑、删除；**全部忘记** 要输入当前密码。

- **保存**：你明确说“记住……”时，智能体会停下来把要记住的内容给你看，**经你确认才保存**，管理员也不能把这一步设成自动执行；
- **后台提炼**（可选）：超级管理员打开参数 `agent.memory.extract` 后，系统定期从空闲的会话里提炼记忆，**只读你自己发出的消息**，不读智能体的回答、工具结果、网页和附件；
- **遮蔽**：保存前把密码、密钥、令牌、身份证号、银行卡号、手机号等常见形式遮蔽掉；
- **使用**：开着记忆的会话里（头部的 **使用记忆** 开关可以逐个会话关掉），智能体参考与当前问题最相关的几条；临时会话不读也不写记忆。记忆内容和对话消息正文在操作日志里以 `***` 遮蔽，不留原文。

::: warning 遮蔽不是万能的
遮蔽规则只认常见的写法：既可能误遮（比如像手机号的工单号），也可能漏掉（比如座机号、没有提示词又不像密钥的口令）。请不要让智能体记住任何敏感信息，记忆可以在 **我的记忆** 里随时查看和删除。
:::

见仓库的[记忆](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#记忆)。

## 限额、急停和用量

自 v1.11.0 起，消费额度按**积分**设置，Token 仅作为实际计量和上下文观测：

| 系统参数 | 默认值 | 范围 |
| --- | --- | --- |
| `agent.limit.turn_credits` | `0` | 每轮积分预算 |
| `agent.limit.user_daily_credits` | `0` | 每用户每日积分预算，UTC 日 |
| `agent.limit.tenant_daily_credits` | `0` | 每租户每日积分预算，UTC 日 |

这三项的 `0` 都表示**不限额**。最多步数、最长时间、并发数、研究模式上限和自动化数量仍各自生效，不能把它们也设为 0 来解除保护。急停参数 `agent.paused` 见上文。

预算在每次模型调用前检查已经记账的消费；达到预算后不发起下一次调用，**单次在途或并行调用可能越过阈值**。这是消费预算，不是预付余额或保证不超出的充值钱包。

**智能体 → 智能体用量** 按日、用户或模型汇总积分与实际用量，并可分页查看每次调用的提供方、精确模型标识、输入、输出、缓存、推理等数字明细、当次费率与积分。相同模型名在不同提供方不会混账，调价不重算历史。图片可显式设置单张后备积分，仅在没有可计价 Token 时使用，不和 Token 费用双收。

缺失字段显示**未知**，不冒充 0；升级前没有细分和费率的记录标为历史数据，不补造历史积分。新调用无法计价时，有限预算会阻止下一次调用。调用失败也不代表没有消费，已经报告的实际用量仍须记录。旧 Token 预算不自动换成积分，也不再作为消费额度。

模型调用前先保存待核对记录；恢复时保留已取得的真实用量和原费率快照，调用明细、每日、本轮及父任务汇总在同一事务内只记一次。没有取得的用量继续标为未知，有限预算可能需要等待核对；任务恢复不把未知消费改成 0。

聊天中的 `/status` 分开显示估算的上下文容量、已记录的本轮和今日积分；上下文圆环不是供应商收费账单。参数说明见仓库的[限额、暂停与用量](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#限额暂停与用量)。

## 子智能体、深度研究、图表 / 图片 / 导出

- **子智能体**：智能体可以把 1 到 3 个互相独立的子任务交给子智能体并行执行。子智能体以发起人的身份运行，**只能用只读工具**，不能再分派、不能反问；要改数据时只能把建议写进摘要，由主会话走正常的审批。主会话里的 **子任务** 卡片按真实状态分组，点击即可原位只读查看过程，主会话和草稿保持；
- **深度研究**：平台技能 **深度研究**（在输入框里用 `$deep-research` 开始）先列计划，再多来源检索和阅读，最后写成一份带编号引用的**研究报告**。这一轮用单独的、更宽的步数和时长上限。引用只认这一轮真正读到的链接，其他的标为“未核实”。报告可以导出 Markdown、打印为 PDF，里面的表格可以单独导出 Excel；
- **图表**：有数字时智能体可以画柱状图、折线图、饼图或表格，页面直接渲染，不执行任何代码；图表的数据可以导出 Excel；
- **图片**：某个模型在设置里标了“图片”时，智能体可以生成图片，存成发起人名下的私有文件，每轮最多 4 张；
- 导出的 Excel 单元格都是纯值，以 `=`、`+`、`-`、`@` 开头的文字会加单引号，不会变成公式。

见仓库的[子智能体](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#子智能体)、[深度研究](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#深度研究)和[图表、图片与导出](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#图表图片与导出)。

## 批量执行和“补齐客户信息”示例

模板带了一个示例：**生成示例 → 示例客户** 里预置了几家知名公司，故意留空了一些字段；平台技能 **补齐客户信息** 配了三个工具（查客户、读客户资料、修改客户资料）。

## 自动化

**智能体 → 自动化** 让智能体在后台运行一个技能或一段提示词，结果进收件箱。每次运行开一个隐藏会话，以**创建人本人**的身份、权限和数据范围执行，每次都重新检查；在运行历史里点“打开会话”可以看全过程。

触发方式有三种：

- **定时**：5 段 cron（分 时 日 月 周）加时区，最短 5 分钟一次，页面提供“每天 9:00”“工作日 9:00”等常用定时；
- **业务事件**：监听某个业务操作（比如新增示例客户），操作记进操作日志后触发；只有创建人能看到这条记录时才运行；
- **手动**：点“立即运行”。

写入模式有四种：

| 写入模式 | 含义 |
| --- | --- |
| 只读（默认） | 不提供任何写入工具 |
| 询问 | 遇到写入时停下，确认卡发到你的收件箱，你在会话里确认后才继续 |
| 预先同意 | 逐个勾选允许的写入工具，勾选新工具时要**输入当前密码**；勾选的写入直接执行，其他写入仍停下等你 |
| 自动审查 | 平台指定了审查模型时才可选：设为自动审查的写入交给审查模型，其他写入停下等你，见上文[自动审查](#自动审查) |

关于**预先同意**：

- 只能搭配**本人的个人技能、本人的个人配置方案或平台技能**，用全租户技能或全租户方案时保存会被拒绝（别人能改它们的内容）；
- 创建人在这个工具上的权限、数据范围或部门变了，管理员改了这个工具的开关或策略，或者绑定的技能正文、方案的额外说明被改了，这项同意就**作废**：写入改为停下等人确认，列表里标为“已失效”，要重新勾选并输入密码；
- 外部 MCP 工具和内置工具不能预先同意。

其他要点：

- 有“共享给全租户”权限的人可以建共享的自动化，本租户的人都能看到，但只有创建人能修改、运行和看历史；创建人被停用或失去权限后，自动化自动停用并通知创建人；
- 同一条自动化同时只运行一次；超级管理员用参数限制每人的条数（默认 20）和每条每天的运行次数（默认 50）；
- 结果总会发站内信，可以另选邮件。

见仓库的[自动化](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#自动化)。

## 安全模型

- **只属于发起人**：会话、审批和提问只有本人能看、能操作，别人打开一律 404；只有发起人本人能确认修改；
- **按用户本人的身份运行**：工具沿用 MCP 的检查（权限点、数据范围、租户和套餐、参数校验、超时、输出里的密钥字段遮蔽）。智能体能做的不会超过发起人自己在页面上能做的；每一轮开始前重新读取身份，用户被停用或删除后就不再继续；
- **写入必须有人同意**：只有四种情况会执行写入——卡片上逐次确认；“信任本会话”（同一工具对同一条记录先确认过一次）；自动化里本人输入密码给出的预先同意（条件变了即作废）；管理员设为自动审查、本人选了自动审查模式后由审查模型放行。确认之后如果权限、审批模式或策略已经变了，调用照样会被拦下；
- **外部内容不可信**：网页、搜索结果和外部 MCP 的输出都当作“只是数据”交给模型。即使模型被网页诱导去改数据，修改也会停在审批卡片上，卡片列出依据的来源；
- **出站请求只连公网**：读网页和外部 MCP 只连公网地址，每次跳转都重新检查。模型的接口地址不做这项检查（为了本机或内网的 Ollama），只有超级管理员能配置；
- **密钥加密**：模型、搜索服务和外部 MCP 的凭据用 `APP_SECRET` 派生的密钥加密存库，只写不读；更换 `APP_SECRET` 后要重新填写；
- **审计**：每次工具调用（包括被拒的）都在 **系统管理 → 日志管理 → 操作日志** 里记一条，标明来自对话页；被修改的数据，修改人照常记为发起人。记忆内容和对话消息的正文在操作日志和接口日志里以 `***` 遮蔽，不留原文。

见仓库的[安全模型](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#安全模型)。

## 给项目开发者

除了给自己的模块加工具、批量目标和技能，运行时还留了三个扩展点，模块把自己的 provider 注册上去即可，不用改智能体模块：

- **内置工具**：只在对话里有意义的能力（要用到本轮的会话、界面条目、反问等）；读写业务数据仍然用 MCP 工具；
- **上下文贡献者**：每轮给模型补一段与本人有关的背景，比如“关于你的记忆”；它不是规则，模型可以不照做；
- **审批审查者**：写入停下等人之前按业务规则先判断，比如驳回明显不对的、把金额过大的交给人；它不能绕过人的同意。

## 已知限制

- 并发对话数是软限制，同时到达的请求可能让一个用户多出一轮；
- 模型、搜索服务和外部 MCP 服务器都是平台配置，租户暂时不能自己添加外部 MCP 服务器；
- 只支持远程 HTTP 的 MCP 服务器，不支持要在服务器上启动进程的 stdio 类服务器；
- 撤回一轮不回滚已经执行的修改；工具超时只结束等待，已经开始的数据库操作无法中断；
- 模型的回答和判断可能出错，审批卡片上的旧值 → 新值和来源请逐条核对。

完整清单见仓库的[已知上限](https://github.com/732124645/qiwu-vue-admin/blob/main/docs/agent.md#已知上限)。
