# 先看这里：写给学生和编程新手

如果你是在校学生，或者刚开始学编程，**没关系，这一栏就是从零开始写的**。

我们假设你：

- 会用电脑，会上网；
- 可能学过一点 HTML、JavaScript 或者 Java，也可能完全没学过；
- **没有**用过终端，**没有**装过数据库，**不知道**前端和后端的区别。

跟着这份教程一步一步做，你会：

1. 在自己的电脑上把一个完整的管理后台跑起来；
2. 明白一个网站从浏览器到服务器再到数据库，是怎么工作的；
3. 亲手修改代码，看到页面发生变化；
4. 做出一个属于自己的功能模块："课程管理"。

## 要花多少时间

| 部分 | 大约需要 |
| --- | --- |
| 读概念、学终端 | 1 小时 |
| 安装开发环境 | 1 ~ 2 小时（主要是等下载） |
| 把项目跑起来 | 30 分钟 |
| 逛后台、第一次改代码 | 1 小时 |
| 做第一个模块 | 1 ~ 2 小时 |

不用一口气做完，每一页都是一个可以停下来的地方。

## 怎么用这份教程

- **按顺序读**。后面的页面会用到前面讲过的东西；
- **每条命令都自己敲一遍**（或者复制粘贴），然后**对照"你应该看到"的输出**。输出对上了再往下走；
- 遇到灰色框里的"提示"、黄色框里的"注意"、红色框里的"危险"，一定要读；
- 看不懂的词，去查[术语表](/beginner/glossary)。

## 出错了怎么办

**出错是正常的**，每个程序员每天都在看报错。重要的是学会看懂它：

1. **不要慌，先看报错的最后几行**，通常那里写着真正的原因；
2. 去[看不懂报错怎么办](/beginner/errors)里找找，常见的问题都在那里；
3. 把**完整的报错信息**复制下来，搜索引擎或者 AI 助手能帮上大忙；
4. 问别人的时候，说清楚三件事：**我在做哪一步、我执行了什么命令、完整的报错是什么**。只说"跑不起来了"，别人是没法帮你的。

## 需要什么样的电脑

- **Mac**：可以；
- **Windows 10 / 11**：可以直接在 Windows 上开发，也可以选择使用 WSL2（在 Windows 里运行一个 Linux），两种方式教程里都有；
- 内存至少 8 GB，硬盘剩余空间至少 10 GB。
