# 术语表

按拼音或字母顺序排列。遇到不认识的词，来这里查一查。

## 基础

| 术语 | 解释 |
| --- | --- |
| **前端** | 在浏览器里运行的部分：页面、按钮、表格。本项目在 `apps/web` |
| **后端** | 在服务器上运行的部分：处理请求、检查权限、读写数据库。本项目在 `apps/server` |
| **全栈** | 前端和后端都会写 |
| **服务器** | 一台一直运行、等待别人来访问的电脑。开发时，你自己的电脑就是服务器 |
| **localhost** | "本机"的意思，指你自己这台电脑，IP 地址是 `127.0.0.1` |
| **端口** | 一台电脑上区分不同程序的编号。本项目：前端 5173，后端 3000，MySQL 3306，Redis 6379 |
| **URL** | 网址，比如 `http://localhost:5173/iam/users` |
| **HTTP** | 浏览器和服务器之间通信的规则 |
| **请求 / 响应** | 浏览器发给服务器的叫请求，服务器回复的叫响应 |
| **状态码** | 响应里的三位数字，表示结果：200 成功、403 没有权限、404 找不到、500 服务器出错… |
| **API / 接口** | 后端提供给前端调用的地址，比如 `GET /api/iam/users` |
| **JSON** | 前后端之间传递数据的格式，`{ "name": "小明" }` |

## 开发工具

| 术语 | 解释 |
| --- | --- |
| **终端 / 命令行** | 输入命令让电脑执行的窗口 |
| **Git** | 代码的版本管理工具，能保存每一次修改的记录 |
| **提交（commit）** | Git 里保存一次修改 |
| **仓库（repository）** | 用 Git 管理的一个项目 |
| **Node.js** | 让 JavaScript 能够在浏览器以外运行的程序。本项目的后端就运行在 Node.js 上 |
| **npm / pnpm** | 下载和管理第三方代码包的工具。本项目使用 pnpm |
| **依赖 / 包** | 别人写好、我们直接拿来用的代码，比如 Vue、NestJS。下载后放在 `node_modules` 里 |
| **VS Code** | 写代码的编辑器 |
| **环境变量** | 程序启动时读取的配置，比如数据库的密码。本项目写在 `apps/server/.env` 和 `.env.local` 里 |
| **热更新** | 保存代码后，页面自动更新，不用手动刷新 |

## 语言和框架

| 术语 | 解释 |
| --- | --- |
| **JavaScript** | 浏览器里运行的编程语言 |
| **TypeScript** | 加上了"类型"的 JavaScript，能提前发现很多错误。本项目的前后端都用它 |
| **Vue** | 前端框架，用来写页面。本项目使用 Vue 3 |
| **Element Plus** | 基于 Vue 的组件库，提供按钮、表格、表单等现成的组件 |
| **NestJS** | 后端框架，用来写接口 |
| **组件** | 页面上一块可以复用的部分，比如一个表格、一个上传框 |
| **装饰器** | 以 `@` 开头、写在类或方法上面的标记，比如 `@Get()`、`@RequirePerm(...)`，给代码加上额外的功能 |
| **zod** | 一个校验数据格式的库。本项目用它定义"编码最多 64 个字"这样的规则，前后端共用 |

## 数据库

| 术语 | 解释 |
| --- | --- |
| **数据库** | 专门存储数据的软件。本项目使用 MySQL |
| **表** | 数据库里的一张"表格"，比如用户表、岗位表 |
| **行 / 记录** | 表里的一条数据，比如一个用户 |
| **列 / 字段** | 表里的一个属性，比如"用户名" |
| **主键** | 唯一标识一行的列，通常是 `id` |
| **SQL** | 操作数据库的语言：`SELECT` 查询、`INSERT` 新增、`UPDATE` 修改、`DELETE` 删除 |
| **索引** | 让查询变快的"目录"。**唯一索引**还能保证某一列的值不重复 |
| **迁移** | 用代码描述对表结构的修改，保证每个人的数据库结构一样 |
| **种子数据** | 初始化时写入数据库的数据，比如默认的菜单、管理员账号 |
| **事务** | 把几个操作打包在一起：要么全部成功，要么全部撤销 |
| **逻辑删除** | 删除时不真正删掉数据，只标记为"已删除" |
| **Redis** | 一个存在内存里、速度很快的数据库，本项目用它做缓存、保存登录状态 |
| **缓存** | 把常用的数据临时存在一个读取更快的地方 |

## 本项目里的概念

| 术语 | 解释 |
| --- | --- |
| **权限点** | 一项具体的操作权限，写法是 `域.资源.动作`，比如 `iam.user.create`（新增用户） |
| **角色** | 一组权限的集合，比如"财务"。给用户分配角色，用户就有了这些权限 |
| **数据范围** | 能看到哪些数据：全部、本部门、本部门及下级部门、仅本人… |
| **字典** | 下拉框的选项，比如"性别：男、女"，管理员可以在后台修改 |
| **参数** | 可以在后台修改的配置，比如"登录失败几次后锁定" |
| **操作日志** | 记录谁在什么时候做了什么操作 |
| **代码生成器** | 根据数据表自动生成前后端代码的工具 |
| **翻译键** | 代码里用来代替文字的标识，比如 `menu.iam.position`，显示时再换成中文或英文 |
| **共享包** | `packages/shared`，前端和后端都会用到的代码 |
