# 接下来学什么

走到这里，你已经：

- ✅ 搭好了开发环境；
- ✅ 把一个完整的管理后台跑了起来；
- ✅ 理解了前端、后端、数据库是怎么配合工作的；
- ✅ 修改过代码，用代码生成器做出了自己的模块；
- ✅ 会用 Git 保存进度。

这已经是很多实际项目的日常工作方式了。接下来，按你的兴趣选一个方向继续深入。

## 在这个项目里继续练习

难度从低到高：

1. **给课程加一个"课程类型"下拉框**：先在种子里定义字典，再在代码生成器里把这一列设为"下拉框"并填上字典编码。参见[字典](/core/dict)；
2. **加一条业务规则**：学分不能超过 10。在 `course.service.ts` 里覆写 `create` 和 `update` 方法，参见 [NestJS 基础](/backend/nestjs)；
3. **加一个自定义按钮**：比如"停课"。跟着[手把手：加一个自定义操作](/backend/tutorial)，从数据库一路做到页面；
4. **做一个树形结构的模块**：比如"课程分类"（有上下级关系）。在代码生成器里选择"树表"模板，参考"生成示例"里的"知识主题"；
5. **做一个主子表**：比如"选课单"，一张单据里包含多门课程。参考"生成示例"里的"发票"。

## 打好基础

这个项目用到了很多技术，不用一次全学会。遇到不懂的，就回头补一补对应的基础：

| 方向 | 学什么 | 推荐资料 |
| --- | --- | --- |
| 网页基础 | HTML、CSS、JavaScript | MDN Web Docs（developer.mozilla.org，有中文） |
| TypeScript | 类型、接口、泛型 | TypeScript 官方文档（typescriptlang.org） |
| Vue 3 | 组件、响应式、组合式 API | Vue 官方文档（cn.vuejs.org，有中文，并且有互动教程） |
| 组件库 | 表单、表格、弹框 | Element Plus 官方文档（element-plus.org，有中文） |
| 后端 | 控制器、服务、依赖注入 | NestJS 官方文档（docs.nestjs.com） |
| 数据库 | SQL 基础：查询、联表、索引、事务 | 任意一本 MySQL 入门教程 |
| Git | 分支、合并、远程仓库 | 《Pro Git》（git-scm.com/book，有中文） |

::: tip 学习建议
- **带着问题去学**：在项目里遇到不懂的地方，再去查对应的知识，比从头啃一本书记得牢；
- **多动手改代码**：改坏了就用 `git checkout` 恢复，大胆去试；
- **读项目里的代码**：代码生成器生成的代码是很好的范例，风格统一，而且每个文件都不长；
- **学会读报错**：参见[看不懂报错怎么办](/beginner/errors)。
:::

祝你学得开心！
