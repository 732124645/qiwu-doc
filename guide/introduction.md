# 介绍

栖梧（Qiwu，项目名 `qiwu-vue-admin`）是一个 **Node 全栈的管理后台模板**。它提供企业后台常用的基础能力，包括登录、权限、组织架构、字典、日志、监控、定时任务、消息、文件、代码生成和审批流程。你只需要在上面写自己的业务。

::: warning 当前状态
项目正在开发中，目前是 **0.10 版本**，工作流模块正在完成。v1.0 发布之前，接口和表结构可能还会调整。下面的功能表标出了每一项的状态。
:::

## 适合谁用

- **学生和编程新手**：从安装环境、终端用法讲起，一步步带你做出第一个功能模块。有专门的[从零开始教程](/beginner/)。
- **想做全栈的前端开发者**：会 Vue 就能上手，后端同样使用 TypeScript，不需要再学一门语言。有专门的[后端入门](/backend/)。
- **从 Java 转到 Node 的后端开发者**：功能和 RuoYi 这类后台对应，概念一看就懂。有专门的[对照文档](/java/)。
- **全栈小团队和外包工作室**：一个仓库交付整套后台，前后端共用类型和校验规则。
- **独立开发者**：做 SaaS 或内部工具时，直接拿它当后台底座。

## 和 Java 后台模板有什么不同

功能范围参考了国内主流的 Java 后台模板，也就是 RuoYi 和芋道的 system/infra 部分，但**代码完全独立编写**。表名、接口、权限写法、字典编码和界面文案都不相同，接口协议也不兼容。

主要区别在于：

- **一种语言**：前后端都是 TypeScript，同一个 zod 规则同时用于后端校验、前端表单和接口文档。
- **更严格的默认安全**：数据范围越界统一返回 404，不泄露记录是否存在；防越权授予、密钥加密存储、上传文件按内容识别类型等措施默认开启。详见[安全基线](/features/security)。
- **原生国际化**：从第一行代码起，所有文案都通过翻译键输出，不是事后补充的。
- **Node 生态的取舍**：Java 专属的功能（比如 Druid 监控、JVM 面板）换成了对应的替代品，例如 MySQL 状态卡和 Node 运行时面板。
